# Support

## Using the application

See the [Student User Guide](USER_GUIDE.md) for account setup, chat,
recommendations, attachments, saved conversations, and reports.

## Reporting a problem

Check existing repository discussions or issues first. If the repository issue
tracker is available, open an issue with:

- The page and action that failed.
- Expected and actual behavior.
- Browser and operating-system versions.
- Steps to reproduce, with personal details removed.
- A screenshot or sanitized browser-console message when useful.

Do not post passwords, verification codes, access tokens, private student
records, or unredacted network logs. Report suspected security issues using
the private process in [SECURITY.md](SECURITY.md), not a public issue.

## Service availability

The frontend is a static site and depends on a separate backend API. If sign-in,
chat, recommendations, or report email fail, retry later and contact the
service administrator with the approximate time and affected feature. A page
loading successfully does not confirm the backend or external AI providers
are available.
